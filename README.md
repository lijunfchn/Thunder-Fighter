## 📖 这是什么

一款**没有游戏引擎、没有第三方库、没有一张图片、没有一个音频文件**的完整 Windows 桌面游戏。

所有飞机、敌机、Boss、粒子、辉光与星云都由 GDI 几何图元逐帧绘制；16 种音效与一整段循环 BGM 全部由代码用正弦波、方波、锯齿波、三角波和噪声**实时合成**。整个游戏就是 `main.cpp` 一个文件（3183 行），编译产物是一个绿色免安装的 `exe`。

| | |
| --- | :-: |
| 开发语言 | C++（单文件 `main.cpp`，3183 行） |
| 图形 | Win32 API + GDI（双缓冲内存位图，全程序化绘制） |
| 音频 | `winmm` / `waveOut` + 自研 24 声道软件混音器 |
| 第三方依赖 | **无** |
| 外部资源文件 | **无**（图片 0 张、音频 0 个） |
| 逻辑帧率 | 固定 60 FPS 时间步长（`QueryPerformanceCounter`） |
| 画面分辨率 | 480 × 720（9:16 竖屏），窗口可自由缩放，保持宽高比 + 黑边自适应 |
| 可执行文件 | `ThunderFighter.exe`（约 2.4 MB，静态链接） |

## ✨ 特性一览

### 🎮 玩法

- **三大游戏模式** —— 剧情闯关（无限关卡，每 5 关迎战 Boss）、生存模式（无尽刷怪，比拼存活时长）、Boss Rush（Boss 车轮战）
- **4 种可切换武器** —— 机枪 / 散射 / 追踪导弹 / 穿透激光，每种都有 ★ → ★★★★ 四级火力成长
- **蓄力激光** —— 长按射击蓄力，松手释放贯穿全屏的重型光柱
- **7 类敌机** —— 小型机、中型机、自爆机、护盾机、召唤机、精英机、Boss，各有独立造型与行为
- **5 种 Boss 弹幕模式** —— 散射 / 双螺旋 / 召唤 / 多阶段变形态 / 突击追踪
- **5 种道具** —— 火力提升、护盾、清屏炸弹、换武器、环绕轨道盾
- **3 架可解锁机体** —— 属性差异化（生命 / 炸弹 / 速度 / 火力），由成就解锁并**永久存档**
- **3 项成就** —— 初出茅庐、无伤通关、弹幕舞者
- **连击倍率系统** —— 连击数越高单次得分倍率越高，受伤即归零
- **V 字形编队**、半血狂暴、慢动作、最高分记录

### 🛠️ 工程

- **手写软件音频混音器** —— 24 个并发发声体、多层叠加音效、指数扫频、颤音、延迟回声、**等功率左右声像定位**（爆炸声按屏幕横坐标定位）
- **纯代码音乐合成** —— 预烘焙 8 小节循环 BGM（底鼓 / 军鼓 / 踩镲 / 三角波贝斯 / 方波琶音 / 带颤音与回声的主旋律）
- **加法辉光渲染** —— 运行时生成 64×64 径向衰减贴图，用 `SRCPAINT` 做加法混合
- **零每帧资源泄漏** —— 字体与辉光贴图按尺寸/颜色缓存复用，静态背景一次性预渲染
- **对象池** —— 子弹、敌机、粒子、道具、飘字全部复用空槽，无频繁分配
- **固定时间步长** —— QPC 高精度计时 + 累加器补帧，逻辑与渲染解耦，慢动作不影响计时器

## 🚀 快速开始

### 方式一：直接下载运行（推荐）

1. 从本仓库下载 `ThunderFighter.exe`
2. 双击运行 —— **无需安装、无需运行库、无外部资源**

> 需要 64 位 Windows 系统。`exe` 为静态链接，不依赖 MSVC 运行库。

### 方式二：一键编译

双击仓库根目录的 **`compile.bat`**：

```bat
compile.bat
```

脚本会自动检测 **MinGW g++** 与 **MSVC cl**，选用可用的编译器完成编译，并提示按键直接启动游戏。

### 方式三：手动编译

```bash
# MinGW (g++)
g++ -o ThunderFighter.exe main.cpp -lgdi32 -lwinmm -static -O2
```

```bat
:: MSVC (cl)
cl main.cpp user32.lib gdi32.lib winmm.lib /Fe:ThunderFighter.exe /O2
```

<details>
<summary><b>编译失败？</b></summary>

- **提示找不到编译器** —— 需要安装 [MinGW-w64](https://www.mingw-w64.org/) 或 Visual Studio（含 C++ 桌面开发工作负载）
- **中文输出乱码** —— 请确保控制台使用 UTF-8；`compile.bat` 已内置 `chcp 65001`
- **建议加上 `-static`** —— 让 `exe` 不依赖 MinGW 运行时 DLL，可独立分发

</details>

## 🎯 游戏系统速览

### 三种模式

| 模式 | 说明 |
| --- | --- |
| **剧情模式** | 标准闯关，每关击落 `12 + 关卡数 × 2` 架敌机。**每 5 关为一个 Boss 关**，关卡数无上限 |
| **生存模式** | 无尽刷怪，永不出现 Boss，难度每 450 帧递增，比拼存活时间 |
| **Boss Rush** | Boss 车轮战，血量随序号递增，弹幕模式按序号循环，结算显示击败数量 |

### 四架战机（3 架可选）

| 机体 | 生命 | 炸弹 | 初始火力 | 速度 | 解锁条件 |
| --- | :-: | :-: | :-: | :-: | --- |
| 标准战机 | 3 | 2 | ★ | 1.00× | 默认 |
| 重装战机 | 4 | 3 | ★ | 0.85× | 成就「初出茅庐」 |
| 疾风战机 | 2 | 1 | ★★ | 1.25× | 成就「弹幕舞者」 |

### 四种武器

| 武器 | 特点 | 适用场景 |
| --- | --- | --- |
| **机枪** | 平行弹幕，火力等级越高弹数越多（1 → 2 → 3 → 5 发） | 通用 |
| **散射** | 5 方向扇形（±31.5°），弹数随等级增加 | 清杂兵 |
| **追踪导弹** | 自动锁定最近敌人，单发伤害 2 | 打高速目标 |
| **激光** | 穿透光束，可贯穿多个敌人 | 打 Boss / 直线排布 |

切换顺序为 **机枪 → 散射 → 追踪导弹 → 激光 → 散射**（注意：切走之后就回不到机枪了）。

### 特殊机制

- **蓄力激光** —— 蓄力达 75 帧后松手，发射 14 × 240 像素、伤害 5 的贯穿重激光
- **半血狂暴** —— Boss 血量低于 50% 时射击间隔减半、每轮额外加射 5 发扇形弹，并出现红色狂暴核心
- **护盾机** —— 必须先击破 3 点前置能量盾，才能伤到本体
- **自爆机** —— 不射击，直冲玩家，贴近 36 像素内自爆
- **召唤机** —— 不射击，每 150 帧召唤 2 架小型机
- **连击** —— 每次击杀连击 +1，得分乘以 `1 + 连击 × 0.1`（10 连击 2.0 倍，无上限），受伤归零

📚 **完整数值与机制说明请见 [`游戏介绍.md`](游戏介绍.md)** —— 包含每种武器的逐级数值、每类敌机的血量与得分、Boss 弹幕构成、道具掉落权重、成就判定细节等。

## 🔬 技术实现

### 渲染：全程序化 + 加法辉光

- **双缓冲**：所有绘制先进入内存位图，再按保持宽高比的方式 `StretchBlt` 到窗口；`WM_ERASEBKGND` 直接返回 1 彻底消除闪烁
- **最近邻缩放**：`COLORONCOLOR` 模式缩放，动态画面不糊不闪不抖
- **加法辉光**：运行时按需生成 64×64 径向衰减贴图（`pow(1-d, 1.9)` 衰减），用 `SRCPAINT`(OR) 做加法混合，实现标题、机体、Boss、道具、子弹的光晕
- **预渲染背景**：垂直渐变深空 + 4 团多层同心椭圆叠加的星云，只构建一次，每帧一次 `BitBlt`
- **三层视差星空**：90 颗星分远/中/近三层，速度与亮度递增，带正弦闪烁
- **伪半透明**：暂停/结算界面的暗化遮罩用 50% 斜纹画刷模拟（GDI 无 alpha 通道的经典替代方案）

### 音频：手写软件混音器

```
waveOut (44.1kHz / 16-bit / 立体声)
   └─ 3 × 1024 帧循环缓冲（约 23 ms 延迟）
        └─ 回调驱动 MixInto()：BGM 流 + 24 个并发发声体实时合成
             └─ 每个音效 = 最多 5 层叠加（波形 / 扫频 / 包络 / 延迟 / 声像）
```

- **波形**：正弦 / 方波 / 锯齿 / 三角 / 噪声，全部由代码数值生成
- **包络**：分段式（起音线性 + 衰减幂曲线），频率支持指数扫频
- **等功率声像**：`gl = cos θ`、`gr = sin θ`，敌机爆炸音按屏幕横坐标定位；散射与导弹的发射音分别偏左/偏右
- **BGM**：启动时预烘焙 8 小节循环（132 BPM，A 小调），含底鼓、军鼓、踩镲、三角波贝斯、方波琶音、带颤音与 3/4 拍延迟回声的主旋律
- **线程安全**：混音线程与主线程用临界区互斥；暂停时暂停 BGM，恢复时**从上次位置续播**

### 主循环：固定时间步长

```cpp
const double STEP = 1.0 / 60.0;                     // 逻辑固定 60 FPS
double scale = (slowmoTimer > 0) ? 0.45 : 1.0;      // 慢动作：只缩放推进量
while (acc >= STEP && steps < 5) {                  // 每帧最多补 5 步
    Update((float)scale);                           // 防止卡顿导致死亡螺旋
    acc -= STEP; steps++;
}
```

- 真实帧时长经 `QueryPerformanceCounter` 测量并钳位到 100 ms，杜绝窗口拖动后的时间跳跃
- 慢动作通过缩放 `dt` 实现：**逻辑调用频率不变，运动与衰减同步变慢，而按帧计数的计时器不受影响**
- 暂停时清空累加器，恢复游戏不会出现"补帧暴走"

### 对象池与资源缓存

| 池 / 缓存 | 用途 |
| --- | --- |
| `playerBullets` / `enemyBullets` | 双方子弹复用空槽，上限 80 |
| `enemies` / `particles` / `powerups` | 敌机 32、粒子 220、道具 6 |
| `floatTexts` | 伤害与得分飘字，上限 40 |
| `fontCache` | 按像素尺寸缓存 `HFONT`，每个尺寸只创建一次 |
| `glowCache` | 按颜色缓存辉光贴图，每种颜色只生成一次 |

## ❓ 常见问题 (FAQ)

<details>
<summary><b>为什么游戏窗口很小 / 能全屏吗？</b></summary>

内部渲染分辨率固定为 480 × 720（9:16 竖屏），但窗口可以**自由拖拽缩放**。画面会保持宽高比等比缩放并自动加黑边，放大到全屏也不会变形或模糊（使用最近邻缩放）。

</details>

<details>
<summary><b>没有声音？</b></summary>

音频通过 `winmm` 的 `waveOut` 输出。如果系统音频设备被独占、被禁用，或驱动异常，`waveOut` 打开会失败 —— 此时游戏会**静默运行**（不崩溃、不影响玩法）。请检查默认播放设备。

</details>

<details>
<summary><b>为什么没有图片和音乐文件？</b></summary>

这是刻意的设计约束：**全部内容程序化生成**。图形用 GDI 图元绘制，音效用振荡器与噪声合成，BGM 在启动时现场烘焙。好处是整个项目就是一个 `cpp` 文件加一个 `bat`，零素材依赖、零体积负担，也便于完整阅读学习。

</details>

<details>
<summary><b>能移植到 Linux / macOS 吗？</b></summary>

当前实现深度依赖 Win32 API（GDI 绘图、`waveOut` 音频、窗口消息循环），需要重写平台层才能移植。GDI 部分可换成 SDL2 / Cairo 等，音频混音器逻辑则是纯算法、可以原样搬走。

</details>

<details>
<summary><b>可以在 GitHub 上直接看到运行效果吗？</b></summary>

仓库目前没有附带截图或录屏。你可以下载 `ThunderFighter.exe` 直接运行，或使用 [ScreenToGif](https://www.screentogif.com/) 录一段 GIF 放进 README —— 欢迎 PR 补充。

</details>
